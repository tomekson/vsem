# VŠEM Dashboard

Studijní dashboard VŠEM — chráněno heslem (StatiCrypt, AES-256).

- **URL:** https://tomekson.github.io/vsem/
- **Obsah:** `index.html` je zašifrovaná verze `vsem-dashboard.html` z privátního repa `VSEMgit`
- **Deploy:** spouští se skriptem `deploy-vsem.sh` z VSEMgit — nikdy needitovat `index.html` ručně

Zdrojová (nešifrovaná) verze dashboardu v tomto repu záměrně není.
